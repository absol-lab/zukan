Privacy Policy — absol Muse Connector

Last updated: November 16, 2026

What this app is

absol Muse Connector is a personal, single-user application operated by the owner of the Pinterest account it connects to. It links the owner's own Pinterest account to the owner's personal AI assistant (Meta Muse) through the official Pinterest API, so that the assistant can view and organize the owner's own boards and pins — mainly to help collect reference images for the owner's art research.

Data accessed

Through the Pinterest API, and only with the owner's authorization, the app can access:

  • Basic account information of the owner (username, profile)
  • The owner's boards and the pins saved on them

The app accesses no other person's data.

How the data is used

  • Data is used only to carry out the owner's own requests, such as listing boards, viewing saved pins, creating boards, and saving pins.
  • Data is never sold, rented, or shared with third parties.
  • Data is never used for advertising.

Storage and security

OAuth credentials for the Pinterest API are stored in Meta Muse's secure credential storage and are never written into this app's code or documents. Pinterest content is processed when the owner makes a request and is not retained beyond what the owner explicitly asks the assistant to save in the owner's own files.

Revoking access

The owner can revoke this app's access at any time from Pinterest account settings (Settings → Privacy and data / Apps), or by disconnecting the connector in Muse. After revocation, the app can no longer access the account.
